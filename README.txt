CLIENT WARS — запуск

Сайт: https://zorg318.github.io/client-wars/

Для участников:
1. Откройте ссылку на сайте.
2. Придумайте никнейм и выберите аватар.
3. Считайте клиентов кнопками + и −.
4. Вкладка «Батл» показывает общую таблицу.

Общая комната уже настроена в приложении: вручную вводить URL и ключ Supabase на телефонах коллег не требуется. Все участники должны пользоваться одной и той же ссылкой.

Важно:
- Это шуточный прототип для небольшой доверенной компании, без настоящей авторизации.
- Никнеймы не являются защищёнными аккаунтами.
- Данные доступны всем, кто имеет доступ к опубликованному приложению и его публичной конфигурации; участники могут менять общую статистику.
- Не храните личные или чувствительные сведения и не используйте приложение для важных рабочих отчётов.
- В клиентском коде допустим только публичный publishable/anon key. Никогда не помещайте сюда secret/service_role key.
- Для серьёзного использования нужны вход участников, серверная проверка прав и ограниченные RLS-политики.

Для владельца:
- Исходный код: https://github.com/zorg318/client-wars
- Страница публикуется через GitHub Pages из ветки main.
- После коммита GitHub Pages может обновляться не мгновенно; при старой версии обновите страницу с очисткой кеша (Ctrl+Shift+R).

Функции:
- До 10 участников в одной комнате.
- Никнейм и выбор аватара.
- Шесть категорий клиентов, личная статистика и общая таблица.
- Достижения и история.
- Синхронизация общей комнаты через Supabase.
